The **Aegis Egress** gateway (`apps/egress-gateway`) hardens all outbound network traffic from your infrastructure. It shields your workloads against malware callbacks, ransomware staging, and compromised LLM agents exfiltrating private tokens or internal databases.

## 🧠 2-Tier Inspection Pipeline

Every outbound DNS query traverses a strict two-stage security filter before external resolution:

```
             [ Outbound DNS Query (Port 5053) ]
                               │
                               ▼
        ┌───────────────────────────────────────────┐
        │   Tier 1: In-Memory CTI Cache (< 2 ms)    │
        │   CrowdSec & Sovereign CERT Feed Cache     │
        └─────────────────────┬─────────────────────┘
                 Match ?      │ No
               ┌──────────────┴──────────────┐
             Yes                             │
               ▼                             ▼
        [ SINKHOLE 0.0.0.0 ]   ┌───────────────────────────┐
        (Immediate Drop)       │ Tier 2: System One AI     │
                               │ Shannon Entropy & Nimble  │
                               └─────────────┬─────────────┘
                                             │
                                             ▼
                                [ Verdict BLOCK / ALLOW ]
```

### 1. Tier 1: In-Memory CTI Feed (< 2 ms)
Microsecond hash table lookup against locally synchronized sovereign Threat Intelligence feeds containing active Command & Control (C2) domains, bulletproof hosting subnets, and ransomware coordination nodes.

### 2. Tier 2: Shannon Entropy & System One AI (Nimble 9B)
If an outbound target domain is absent from known blocklists:
* **Shannon Entropy Analysis** : Algorithmic domains generated by DGA routines (e.g. `a8f93bc01d9f4e2a.xyz`) demonstrate statistical character randomness exceeding natural phonetic thresholds (> 3.8).
* **System One Probabilistic Inference** : The on-premise **Nimble 9B** SLM (executed locally via Ollama with zero US Cloud dependency) evaluates lexical risk vectors and returns a deterministic `BLOCK`, `QUARANTINE`, or `ALLOW` decision in under 50 ms.
