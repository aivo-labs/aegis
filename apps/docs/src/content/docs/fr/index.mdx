## Engagements & Conformité Réglementaire

<CardGrid stagger>
  <Card title="🛡️ Durcissement ANSSI & NIS 2" icon="approve-check">
    Conçu pour respecter les règles d'hygiène informatique de l'ANSSI et accompagner les entités essentielles (EE) et importantes (EI) vers la conformité à la directive européenne NIS 2 et au règlement DORA.
  </Card>
  <Card title="🌿 Norme VS EFRAG & RGESN 2024" icon="star">
    Attribution physique auditable en Joules bruts pour les commissaires aux comptes RSE, sans approximation basée sur des ratios monétaires. Évaluation continue de l'EcoIndex v3 de vos applications web.
  </Card>
  <Card title="🇪🇺 Immunité Cloud Act (100% Souverain)" icon="seti:lock">
    Zéro dépendance envers des API ou backends tiers américains. Le modèle de langage d'analyse sémantique Nimble 9B s'exécute localement sur votre propre CPU/GPU sans qu'aucun jeton ne quitte votre réseau.
  </Card>
  <Card title="⚖️ 100% Open Source AGPLv3" icon="open-book">
    Zéro coût de licence par siège ou utilisateur. L'intégralité du code source est librement auditable et modifiable, garantissant l'indépendance totale de votre système d'information.
  </Card>
</CardGrid>
